# Event-Flow

Event-Flow is a web-based event management dashboard prototype built to demonstrate how event organizers can manage events, monitor registrations, and handle attendee check-ins through a centralized interface.

## Features

- **Dashboard Overview**: View registration statistics, attendance summaries, event capacity, and registration trends.
- **Event Management**: Create, edit, publish, unpublish, and delete events.
- **Registrant Management**: Search and filter registrants by name, email, registration code, and status.
- **Registrant Details**: View attendee information, including contact details and registration status.
- **Attendance Management**: Find attendees by name or registration code and confirm check-ins.
- **Event Selection**: Switch between events to view their respective data.
- **Responsive Interface**: Navigate the dashboard through a layout designed for different screen sizes.

## Tech Stack

- **HTML5**: Semantic web structure.
- **CSS3**: Styling, layout, and responsive design.
- **JavaScript**: Dashboard interactions and application logic.
- **JSON-style Mock Data**: Sample event and registrant records for demonstration.

## Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code or another code editor.
- A local development server, such as the Live Server extension.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/Event-Flow.git
   cd Event-Flow
   ```

2. Open the project in your code editor.

3. Run `index.html` using a local development server.

4. Open the local URL in your browser to explore the dashboard.

## Project Status

Event-Flow is a front-end prototype built with vanilla HTML, CSS, and JavaScript. It uses mock data and browser-session state for demonstration purposes. Backend integration, persistent database storage, authentication, and full reporting functionality are not included in the current implementation.
